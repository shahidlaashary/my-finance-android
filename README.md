# My Finance

A personal finance application built with Flutter.

## Initial targets
- Android
- Windows Desktop

## Planned modules
- Income and expenses
- Accounts and transfers
- Loans and repayments
- Assets and savings goals
- Budgets and reports
- Multi-currency support
- Recurring transactions
- Transaction photos and PDF attachments
- Firebase backup and synchronization
- Urdu, English, Arabic and Hindi
- PIN and biometric security

## Development
Flutter SDK is required.

Run:

flutter pub get
flutter run
